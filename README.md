# CSReborn private mod updates

This private repository is the release feed used by CSReborn launchers.

- The `launcher-latest` release contains `CS2GC-Portable-25966348.zip` only.
- The launcher verifies GitHub's SHA-256 asset digest and every payload file before updating.
- Do not upload Counter-Strike game files, player data, credentials, or launcher executables here.

The repository is private. Launcher builds use a read-only fine-grained token; the publishing workflow uses a separate write token.
